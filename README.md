# Nesto Web

React + TypeScript SPA for the Nesto task/list management app.

## What This Does

Web frontend for Nesto. Consumes the backend REST API and provides the UI for managing tasks and lists, including drag-and-drop reordering of the recursive tree structure.

## Tech Stack

- **Language**: TypeScript
- **Framework**: React
- **Build**: Vite
